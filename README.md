# C Programming: Pointers and Arrays

## 
About
This repository contains 8 C programming problems focused on pointers, arrays, loops, and multidimensional arrays. These programs help build basic C programming and logical thinking skills.

##  Programs Included

1. **Pointer Arithmetic** – Accessing array elements using pointers.
2. **Multiplication Table of 5** – Storing and displaying multiples of 5 using an array.
3. **User-Input Multiplication Table** – Generating a multiplication table for a number entered by the user.
4. **Count Positive Integers** – Counting positive numbers in an array using a function.
5. **Array Function Practice** – Practicing functions and array traversal.
6. **2D Array Multiplication Tables** – Storing multiplication tables of 2, 7, and 9 in a two-dimensional array.
7. **User-Input 2D Array Tables** – Generating multiplication tables for three user-entered numbers.
8. **3D Array Memory Addresses** – Printing the memory addresses of elements in a three-dimensional array.

##  Concepts Used
- Pointers and pointer arithmetic
- One-dimensional arrays
- Two-dimensional and three-dimensional arrays
- `for` loops and nested loops
- Functions and conditional statements
- User input using `scanf()`
- Output using `printf()`
- Memory addresses using the address-of operator (`&`)

##  Requirements
- C compiler (GCC recommended)
- VS Code or any C programming IDE

##  How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Save the program in a `.c` file.
4. Compile and run using GCC:

```bash
gcc filename.c -o program
./program
```

On Windows, run the compiled program using:

```bash
program.exe
```

Replace `filename.c` with the name of your C source file.
